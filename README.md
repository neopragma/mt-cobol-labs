# M&T COBOL Labs 

This repository contains instructions for labs, starter code, and sample solutions for the M&T COBOL application development class October 19 - September 1, 2026. 

Class participants should fork this repository under their own Github IDs so that each person will have their own copy of the material and a place to save their own work for future reference.
