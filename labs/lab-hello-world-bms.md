# Lab: "Hello, World!" using BMS

Goal: Convert the plain version of "Hello, World!" to use a BMS mapset.

## Step 1: Code the BMS mapset 

Code a BMS mapset that defines appropriate fields for your "Hello, World!" message and positions them where you want them to appear on the screen. 

## Step 2: Assemble the BMS mapset

Set up JCL based on the samples provided for assembling a BMS mapset, and run the job to assemble your mapset.

Note how the executable mapset is stored in the CICS SDFHLOAD libary and the corresponding data layout (DSECT) is stored in your COBOL copy library.

## Step 3: Compile the program for the CICS environment 

Compile and bind this version of your "Hello, World!" program.

## Step 4: Define the mapset as a program resource in CICS 

Use CEDA to define the mapset as a program resource. If your userid lacks the necessary access rights, the instructor will do it for you while you watch.

## Step 5: Test the transaction 

Run the transaction and tweak things until they are working as you want.
