# Lab: Find your z/OS data sets using ISPF 

ISPF is the basic user interface for working with z/OS. Unless a third party front-end product is installed, ISPF will be the working environment where you spend most of your time when working on this system.

ISPF contains numerous functions organized under a hierarchy of panels. It takes time to learn your way around. 

For this lab, we'll begin by locating the data sets that are allocated under your z/OS userid. 

On the ISPF Primary Option Menu, enter "3" (for Data Set Utilities) in the Command field and press Enter. That takes you to another menu where you can select one of the data set utilities. Enter "4" and press Enter.
