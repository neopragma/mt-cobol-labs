# Lab: Your "Hello, World!" CICS program 

Goal: To have a working sample CICS program in your repository.

## Step 1: Code the program based on the sample 

Write your own COBOL CICS program to display "Hello, World!" on the terminal emulator screen. All the necessary code is available in the sample program, [HELLO2](../samples/cics/cobol/HELLO2.cbl). The point of this lab is not to challenge you to figure this out on your own, but to help you get a simple working program up and running so you can use it as a base going forward.

## Step 2: Compile the program for the CICS environment 

Based on the demo of compiling and binding a COBOL program for CICS, compile and bind your "Hello, World!" program. 

## Step 3: Defining the program and a transaction to run it as CICS resources 

Guided by the instructor, define your program and a transaction to CICS, install the resource definitions, and run the transaction. 

Note: If the student userids don't have sufficient access rights to define CICS resources, the instructor will do it for you while you watch.
