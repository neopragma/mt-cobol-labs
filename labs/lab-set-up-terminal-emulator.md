# Lab: Set up your 3270 terminal emulator 

Your VM has one or more 3270 terminal emulator programs installed. A terminal emulator simulates the functionality of an IBM 3270 terminal, the type of device that was used to access IBM mainframe systems in the Olden Days. As the mainframe is strictly a back-end system, IBM paid little attention to the user interface over the years. For that reason, 3270 terminal emulation remains the basic way to access these systems. 

The z/OS system we are using for the class exposes an endpoint for 3270 terminal connections consisting of an IP address and port number. These values are the same for all participants. Configure the terminal emulator on your VM to connect to this endpoint. Try to connect and see if something reasonable appears in the terminal emulator window on your VM.
