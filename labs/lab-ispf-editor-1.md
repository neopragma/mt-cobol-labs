# Lab: Practice using the ISPF Editor 

Goal: Practice using basic ISPF Editor commands and line commands to create, modify, and save library members.

## Step 1: Guided practice 

The instructor will guide you, as a group, through several basic editor operations. Then you will spend some time practicing on your own.
