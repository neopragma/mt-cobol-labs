# Lab: COBOL tables

Goal: Practice working with COBOL tables.

## Step 1: Upload the starter code for the AIRPORT exercise

Upload starter program [AIRPORT](../starters/cobol/AIRPORT.cbl) to your <userid>.LAB.COBOL library. 

## Step 2: Fill in the missing code 

Comments in the source code will guide you through adding logic to perform serial and binary searches of the Airports table.

## Step 3: Run the program and check the output 

View the output in SDSF to verify the displayed results are as expected.

## Step 4: Upload the starter code for the INVOICE exercise

Upload starter program [INVOICE](../starters/cobol/INVOICE.cbl) to your <userid>.LAB.COBOL library. 

## Step 5: Fill in the missing code 

Comments in the source code will guide you through adding logic to calculate the final invoice amount for a hypothetical sales transaction.

## Step 6: Run the program and check the output 

View the output in SDSF to verify the final invoice amount is calculated and displayed correctly.
