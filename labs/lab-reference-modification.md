# Lab: Reference Modification

Goal: Practice using Reference Modification in COBOL.

## Step 1: Upload the starter code

Upload sample program [REFMOD](../samples/cobol/REFMOD.cbl) to your <userid>.LAB.COBOL library. 

## Step 2: Fill in the missing code 

Comments in the source code will guide you through adding MOVE statements that use Reference Modification to alter the contents of fields in Working-Storage.

## Step 3: Run the program and check the output 

View the output in SDSF to verify the values of the fields were changed as specified.
